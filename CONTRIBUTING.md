# Как помочь проекту

Спасибо, что хочешь сделать каталог лучше!

## Что можно прислать

- **Новый проект**: декомпиляция, рекомпиляция, порт, ремейк движка, браузерный порт.
- **Исправление**: мёртвая ссылка, устаревшие данные, ошибка в описании.
- **Урок или раздел гайда**: пошаговые инструкции, особенности запуска на конкретной платформе.
- **Перевод описаний** проектов на русский.

## Правила для новых записей

1. Ссылка ведёт на **исходный код** (GitHub, GitLab, Codeberg и т. п.) или официальную страницу проекта.
2. Никаких ROM, ISO, игровых ресурсов и ссылок на них. Такие PR будут закрыты.
3. Указаны: название игры, платформа оригинала, тип проекта, есть ли готовые релизы.
4. Описание — 1 предложение, своими словами, без маркетинга.
5. Запись добавляется в подходящий раздел и таблицу с сохранением сортировки (по score, затем по звёздам).

Формат строки таблицы:

```markdown
| [Название игры (проект)](https://github.com/owner/repo) | Платформа | ⭐ | Score | ✅ |
```

## Как отправить

1. Сделай форк репозитория.
2. Создай ветку: `git checkout -b add-project-name`.
3. Внеси изменения и проверь, что Markdown корректно отображается.
4. Открой Pull Request с кратким описанием.

Если проект хочется добавить и в англоязычный первоисточник, отправь его также в [SubmitGame/awesome-decomp-games](https://github.com/SubmitGame/awesome-decomp-games).

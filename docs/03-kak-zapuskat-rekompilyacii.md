# Урок 03. Как запускать рекомпиляции и порты: Windows, macOS, Linux, Android

[← К оглавлению](../README.md)

## Общая схема

1. Найди проект в [каталоге](../README.md) и открой его страницу на GitHub.
2. Перейди в **Releases** (справа на странице репозитория) и скачай сборку под свою ОС.
3. Подготовь файл **своей** игры нужной версии (см. README проекта).
4. Запусти программу и укажи файл игры.
5. Настрой графику, управление, моды.

## Системные требования (ориентир)

| Компонент | Минимум | Комфортно |
|---|---|---|
| ОС | Windows 10, macOS 12, Ubuntu 22.04 | актуальные версии |
| GPU | с поддержкой Vulkan 1.2 / D3D12 / Metal | любая дискретная за последние 6–7 лет |
| CPU | 2 ядра | 4+ ядра |
| RAM | 4 ГБ | 8 ГБ+ |

Рекомпиляции N64 и большинство портов работают даже на встроенной графике и Steam Deck. Рекомпиляции Xbox 360 тяжелее.

## Windows

1. Скачай архив `*-Windows.zip` из Releases и распакуй в папку без кириллицы и пробелов (например, `C:\Games\Zelda64Recomp`). Некоторые проекты плохо работают с путями на кириллице.
2. Если не запускается, поставь **Visual C++ Redistributable** (x64) и обнови драйверы видеокарты.
3. Windows SmartScreen может предупредить о неподписанном файле: это нормально для open-source сборок, если файл скачан с официального GitHub.

## macOS

1. Скачай сборку для Apple Silicon (arm64) или универсальную.
2. Перетащи `.app` в «Программы».
3. Если система пишет «приложение повреждено»:

```bash
xattr -dr com.apple.quarantine /Applications/Название.app
```

## Linux и Steam Deck

- Многие проекты распространяются как **AppImage** или **Flatpak**:

```bash
chmod +x Zelda64Recompiled-*.AppImage
./Zelda64Recompiled-*.AppImage
```

- На Steam Deck: переключись в режим рабочего стола, скачай AppImage, добавь его в Steam как стороннюю игру («Add a Non-Steam Game») и запускай из игрового режима.
- Нет звука или геймпада — установи `libsdl2` и проверь права пользователя на `/dev/input`.

## Android

- Скачай `.apk` из Releases проекта (например, Ship of Harkinian, Zelda64Recomp Android, UnleashedRecomp Android, OpenMW, VCMI).
- Разреши установку из неизвестных источников только для файлового менеджера, из которого ставишь APK.
- Дай приложению доступ к папке с файлами игры.
- Для рекомпиляций Xbox 360 нужен флагманский чип последних лет; N64-рекомпиляции идут на большинстве современных телефонов.

## Настройки, которые стоит включить

| Настройка | Где обычно найти | Эффект |
|---|---|---|
| Разрешение / масштаб | Graphics | Чёткая картинка в 1440p/4K |
| Ultrawide / Aspect ratio | Graphics | Широкоформатный режим без растяжения |
| Frame rate / Interpolation | Graphics | 60/120/144 FPS |
| MSAA | Graphics | Сглаживание |
| Gyro aiming | Controls | Прицеливание гироскопом геймпада |
| Mods | Mods / папка `mods` | Моды из Thunderstore или GitHub |

## Моды для рекомпиляций N64

Большинство рекомпиляций на базе N64Recomp поддерживают мод-API. Обычный порядок:

1. Скачай мод (`.nrm` или архив) из Thunderstore или GitHub.
2. Открой в программе меню **Mods** → **Install mods** или положи файл в папку `mods` рядом с программой.
3. Перезапусти и включи мод в списке.
